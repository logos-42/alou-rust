# Alou - AI 协作团队平台

> **不再和一个 AI 说话**  
> **让一群 AI 为你工作**

---

## 一句话介绍

Alou 让你创建 AI 团队，多个 AI 一起帮你完成任务。

---

## 为什么需要 Alou？

现在的 AI 工具都是**一对一对话**：你问，它答。然后你再去问另一个 AI。

**效率低下。**

Alou 的做法完全不同：

1. 你描述任务
2. 系统自动分配 AI 团队（规划师、设计师、程序员...）
3. **AI 们在一个协作空间里一起工作**
4. 你看着它们协作，拿到完整结果

**这就是魔法时刻。**

---

## 使用场景

### 场景：做一个旅行规划网站

**传统方式**：
1. 问 ChatGPT：「旅行网站需要哪些功能？」
2. 问 Claude：「帮我设计 UI」
3. 问 Copilot：「帮我写代码」
4. 自己整合所有结果

**Alou 方式**：
1. 打开 Alou，点击「创建协作」
2. 输入：「帮我做一个旅行规划网站」
3. **看着三个 AI 自动分工、协作、出方案**
4. 拿到完整结果

**结果一样？不。体验天差地别。**

## 快速开始

### 安装

```bash
# 克隆项目
git clone https://github.com/logos-42/alou-rust.git
cd alou-rust/alou-desktop

# 安装依赖
npm install

# 启动开发服务器
npm run dev
```

### 使用

1. 打开浏览器访问 `http://localhost:1420`
2. 点击「✨ 创建协作」
3. 输入你的任务描述
4. 看着 AI 团队开始协作
5. 拿到完整结果

## 技术栈

- **前端**: React + TypeScript + Vite
- **桌面端**: Tauri 2.0
- **AI 集成**: Claude / DeepSeek API
- **状态管理**: Zustand
