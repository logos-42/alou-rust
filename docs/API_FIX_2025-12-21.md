## 故障排查指南

### 如果再次出现 401 错误

1. **检查 API Key 是否有效**
   ```powershell
   .\scripts\test-deepseek-api.ps1 -ApiKey 'your-api-key'
   ```

2. **检查 Workers Secret 配置**
   ```powershell
   npx wrangler secret list
   ```

3. **更新 Secret（如果需要）**
   ```powershell
   npx wrangler secret put AI_API_KEY
   ```

4. **重新部署 Workers**
   ```powershell
   npm run deploy
   ```

5. **等待 1-2 分钟让配置生效**

6. **查看 Cloudflare Dashboard 日志**
   - 访问: https://dash.cloudflare.com/
   - 进入: Workers & Pages → alou-edge → Logs

### 错误信息解读

- **401 Authentication Fails (governor)**: API Key 认证失败或限流
  - 检查 API Key 是否有效
  - 检查 DeepSeek 账户余额
  - 等待一段时间后重试（可能是限流）

- **500 Internal Server Error**: Workers 内部错误
  - 查看 Workers 日志获取详细信息
  - 检查代码是否有错误
  - 确认所有依赖和配置正确

## 注意事项

1. **Secret 更新需要重新部署**: 虽然 Secret 更新后可能自动生效，但建议重新部署以确保所有实例都使用新配置

2. **配置生效时间**: Secret 更新后可能需要 30-60 秒才能完全生效

3. **API Key 安全**: 
   - 不要将 API Key 提交到代码仓库
   - 使用 Workers Secrets 存储敏感信息
   - 定期轮换 API Key

4. **DeepSeek API 限制**:
   - 注意 API 调用频率限制
   - 监控账户余额
   - 注意 "governor" 错误可能表示限流
